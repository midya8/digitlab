DIGITLAB / LIVE MODEL INSPECTOR

Clean accuracy is not a robustness guarantee.

Inspect two small models trained from scratch on real UCI 8x8 block-count digits. Try an original test example or edit the grid. Everything below runs in this page, with no account, upload, paid API or prediction server.

Manual JavaScript inference and input gradients

1. Inspect an input

Draw with a mouse or touch. Keyboard: Tab into the grid, arrow keys move, Space or Enter paints the selected count. Inputs are block counts, not a camera image or ordinary handwritten-text OCR.

2. Read the model scores

Current predicted digit

Softmax scores are not calibrated probabilities of correctness. A high score can accompany a wrong prediction.

The simple baseline wins the frozen clean test. Exact 1NN: 1,760 / 1,797 correct. MLP: 1,734. Linear: 1,698. The baseline is not running in this page and this editable input is not an accuracy measurement.

3. Try one bounded input change

FGSM increases cross entropy for an explicit loss label, clips pixels to [0,1], and stays within a chosen L-infinity radius. It can fail to find an existing error. This demo is not a certificate, and the perturbation is not claimed to preserve a human label or be imperceptible.

A sample supplies its recorded label. Editing clears that label; choose one yourself before attacking. This choice does not affect the ordinary prediction.

The original editable grid stays unchanged. The visualization rounds continuous perturbed pixels to grayscale; inference uses their full numeric values.

4. Attribute a class-logit change

Integrated Gradients divides a selected class logit's change from an explicit baseline among the 64 inputs. This is not causal feature importance, class probability or proof that the model is trustworthy. A small completeness residual checks a sum, not explanation quality.

Neither baseline is assumed neutral or realistic. The mean uses only 3,062 frozen fitting rows, not validation or test rows. Changing the baseline changes the question.

Blue: positive · Orange: negative · White: zero. Signs refer to this logit change, not the effect of deleting a feature. Colors rescale per map; compare the values, not color alone.

All 64 signed contributions, row-major

    The established straight-line method is evaluated algebraically for these linear/tanh models. Independent quadrature checks live in the repository. This floating implementation is not an exact certificate.

    What the research does, and what this page does not

    Protocol, exact proofs and limitations

    Models were selected by validation NLL using only the official training file before parsing the separate official test file. The fixed fitting/validation split has 3,062 / 761 rows. Model weights and source dataset hashes are preserved in the repository.

    The repository separately proves clipped-box margins and adversarial-radius infima for the real affine function of the linear model's loaded binary64 coefficients. Those exact rational proofs are not executed here, do not certify floating-point evaluation on mathematical boundary ties, and do not apply to the nonlinear MLP.

    Original samples are the lowest official test-row index for each digit label, not a representative selection. Edited inputs may be outside the training distribution. Neither the historical test accuracy nor the displayed scores promise accuracy on your drawing.
